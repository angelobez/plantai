# PROTOTYPE: MVP screens (throwaway)

Throwaway prototype for the ticket [Telas no Claude Design](https://github.com/angelobez/plantai/issues/9).
Source files of the Claude Design canvas: one `.dc.html` per artboard, laid out by `canvas.json`.

- `M-*.dc.html`: the chosen direction, one file per MVP screen (page "Telas do MVP").
- Everything else: the explorations that led there (directions A, B, C and variations A1 to A6).

Do not merge into `main`. The decision lives in the ticket's resolution.
