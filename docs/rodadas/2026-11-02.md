## [Logs da API: id de requisição, retenção e IP](https://github.com/angelobez/plantai/issues/77)

### Q4. Id de requisição

- **(a)** O `ApiClient` gera o `X-Request-Id`; a API aceita (ou gera, se faltar), grava no log e devolve no cabeçalho e no `requestId` do problem details; o app anexa o id ao Crashlytics
- **(b)** Só a API gera
- **(c)** Tracing do Sentry

> 💡 **Recomendação: (a).** Funciona mesmo quando a requisição nem chega à API e não depende de fornecedor.

**✏️ Resposta:** ok

### Q5. IP e retenção dos logs

- **(a)** Redigir `x-forwarded-for` e guardar logs por 30 dias
- **(b)** Redigir e guardar 90 dias
- **(c)** Manter o IP e guardar 30 dias

> 💡 **Recomendação: (a).** Menos dado pessoal e nada a declarar sobre IP na Play.

**✏️ Resposta:** ok
